simple android application for watching iptv
it should use as low ram as possible
main view has channels in a grid with their logos
a button to add new channel
adding new channel requires inputting a name, an m3u8 link, optionally a logo image link
links can be read from qr code
logos should be saved locally
tv streams have only sound control
touching screen while a stream is playing shows up channel list on the left for 10 seconds while shrinking display
it should handle connection problems gracefully
a loading spinner should show up on connection problem and it should play again when connection is established
